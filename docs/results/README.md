### 0.1 官方模型 deepseek-flash + 官方 8 条事件（2026-10-30，最终验收）

把练习配置换成 **24×24 + 裁判自带的 8 条官方事件**（爆炸/幻术/天使/无双/分裂/辣椒/洁身/潘潘），模型用官方统一的 **deepseek-flash**，四席位仍全是我们自己的程序：

| 席位 | 分数 | 资源 | 伤害 | 任务 | 无效 | AI 成功/尝试 |
|---|---|---|---|---|---|---|
| A | **42.5** | 50 | 2100 | 3/3 | 0 | 55/55 |
| B | **42.5** | 50 | 1256 | 3/3 | 0 | 59/59 |
| C | **42.5** | 50 | 2295 | 3/3 | 0 | 57/57 |
| D | **42.5** | 50 | 1365 | 3/3 | 0 | 58/58 |

**证明了三件事**：

1. **flash 能稳定理解公告**：A 席位日志原文「我在爆炸矩形内，Tick 15 前离开 [3,3]-[7,7] 区域以避免扣血」「避开幻术矩形 [8,3]至[12,7]」；
2. **AI 调用零失败**（55~59 次/席位，全部 200）；日志里的“事件理解未拿到结果”是我们自己的节流（0.8 s 冷却/预算），不是网关失败；
3. **24×24 + 8 事件下分数结构不变**（四席位 42.5、无效动作 0）。
