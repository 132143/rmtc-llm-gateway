## 三、跑的方法（可复现）

```bash
source /opt/ros/humble/setup.bash            # ← 漏了这行会静默 0 分（踩过两次）
export ROS_DOMAIN_ID=27 ROS_LOCALHOST_ONLY=0 RMW_IMPLEMENTATION=rmw_fastrtps_cpp
export RMTC_SEAT=A RMTC_TEAM_TOKEN=practice-A
export RMTC_AI_URL=http://127.0.0.1:8080/v1/chat/completions
# 裁判端（真实模型）：PRACTICE_LLM_URL / PRACTICE_LLM_KEY / PRACTICE_MODEL 由裁判终端提供
cd ~/rmtc_practice && ./start_referee.sh --stage 2 --ai-mode real
curl -s -X POST http://127.0.0.1:8080/api/start -d '{"stage":2,"tick_ms":500,"max_ticks":500}'
cd ~/rmtc-seal31 && python3 -m contestant.bot_node --seat A --stage 2
curl -s -X POST http://127.0.0.1:8080/api/resume -d '{}'
```

陪练要单独起（否则 B/C/D 站着不动，我们会白拿 60 分）：

```bash
for seat in B C D; do RMTC_TEAM_TOKEN=practice-$seat ./start_bot.sh $seat "练习陪练$seat" & done
```

## 四、这次踩到的两个坑（已写进 README）

| # | 坑 | 现象 | 修法 |
|---|---|---|---|
| 1 | 忘了 `source /opt/ros/humble/setup.bash` | 进程直接退出并打印"这个节点需要 ROS 2"，四席位全 0 分 | 启动脚本第一行就 source，并断言 `python3 -c "import rclpy"` 成功 |
| 2 | 只起裁判不起陪练 | 陪练注册了但不动，我们白拿 60/60，看起来"很强" | 竞争局必须 `start_bot.sh B/C/D` 各起一个 |

> 这两条都会让"跑过了"的结论失真：前者看起来像策略失效，后者看起来像策略超神。
