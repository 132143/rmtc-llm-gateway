## 令牌/网关（无默认值）

第二阶段启动**必须**显式设置 `RMTC_TEAM_TOKEN` 与 `RMTC_AI_URL`；缺任一立刻报错退出。
**不要设置 `RMTC_MODEL`**：官方要求使用统一默认模型（`bot_node` 也不读这个变量）。

## 万全设计（现场任何不确定都不至于丢分）

| 风险 | 兜底 |
|---|---|
| 现场给的网关地址写法不同 | `RMTC_AI_URL` 支持 基址 / 基址+v1 / 完整地址，自动补全 |
| 上游不认 `thinking` / `response_format` | 请求体逐级降级：全量 → 去掉被拒字段 → 最小请求，最多 3 次，任意一级成功即停 |
| 400 但没说哪个字段 | 先丢 `thinking`，再丢 `json_object` |
| 令牌/地址没设 | 启动即报错退出（不静默 401） |
| 开赛前不确定能不能用 | `python -m scripts.preflight` 六项自检，全绿再上场 |
| 策略在某张图上水土不服 | 现场把 `decision_type` 切 `turtle`（保命）或 `economy`（纯经济） |
